# 경기 일정 운영 안내

앱 홈의 경기 카드는 Supabase `games` 테이블을 그대로 보여 줍니다. 실시간 점수는 보여 주지 않고, 경기 중에는 "네이버 문자중계 보기" 버튼으로 연결합니다.
운영자가 할 일은 **시즌 전 일정 올리기**, **매일 선발투수·결과 입력**, **일정이 바뀌면 고치기** 세 가지입니다.

> 일정·선발·결과는 KBO 발표를 보고 직접 정리해 입력하세요. 다른 서비스의 데이터를 프로그램으로 통째로 가져오지 마세요.

## 칸 설명 (`games`)

| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 경기 고유 번호. 가져오기 때 비워 두면 `날짜-원정-홈-차수`로 자동 생성 | `20270327-doosan-nc-0` |
| `game_date` | 경기 날짜 | `2027-03-27` |
| `start_time` | 시작 시각 (한국 시간) | `18:30` |
| `away_team` / `home_team` | 원정팀 / 홈팀 id | `doosan`, `nc` |
| `stadium_id` | 구장 id. 비워 두면 홈팀 구장 | `changwon` |
| `game_no` | 0 = 일반, 1·2 = 더블헤더 1차전·2차전 | `0` |
| `status` | `scheduled`(예정) / `final`(종료) / `canceled`(취소) | `scheduled` |
| `away_starter` / `home_starter` | 선발투수 이름 (발표 전엔 비움 → 앱에 "선발 미정") | `곽빈` |
| `away_score` / `home_score` | 최종 점수. `final` 이면 둘 다 필수 | `4`, `6` |
| `naver_url` | 네이버 스포츠의 그 경기 페이지 주소 (선택). 비우면 날짜별 일정 페이지로 연결 | `https://m.sports.naver.com/...` |

팀 id: `nc` `kia` `samsung` `lg` `doosan` `kt` `ssg` `lotte` `hanwha` `kiwoom`
구장 id: `jamsil` `suwon` `incheon` `daegu` `gwangju` `changwon` `sajik` `daejeon` `gocheok`

## 1. 시즌 전: 일정 올리기

1. [games_template.csv](games_template.csv)를 엑셀이나 구글 시트로 열어, KBO가 발표한 정규시즌 일정을 한 줄에 한 경기씩 채웁니다. (예시 3줄은 지우세요)
   - `id`, `stadium_id`, `status`, 선발, 점수, `naver_url` 은 비워 둬도 됩니다.
   - 날짜는 `2027-03-27`, 시각은 `18:30` 형식. 저장은 **CSV (UTF-8)** 로.
2. Supabase 대시보드 → **Table Editor** → `games_import` 테이블 → **Insert → Import data from CSV** 로 파일을 올립니다.
3. **SQL Editor** 에서 실행:
   ```sql
   select public.apply_games_import();
   ```
   반영된 경기 수가 나오고, `games_import` 는 자동으로 비워집니다.

같은 파일을 고쳐서 다시 올려도 됩니다. **같은 `id` 는 덮어쓰고, 빈 칸은 기존 값을 그대로 둡니다.** (이미 입력한 선발·점수가 지워지지 않아요)
한 파일 안에 같은 경기가 두 번 있으면 오류가 나니 중복 줄을 지우고 다시 올리세요.
가져오기 화면에서 빈 칸 때문에 오류가 나면, 빈 칸 열을 지우고 올리거나 아래 SQL 방식으로 입력하세요.

## 2. 매일: 선발투수와 결과

**Table Editor → `games`** 에서 그날 경기 줄을 눌러 고칩니다 (엑셀처럼 칸을 눌러 수정).

- **전날 저녁 (선발 발표 후)**: `away_starter`, `home_starter`
- **경기 후**: `away_score`, `home_score` 를 넣고 `status` 를 `final` 로.
  → 그 경기를 직관 기록한 사용자들의 승·무·패가 **자동으로** 채워집니다. 점수를 고치면 다시 계산돼요.

SQL 로 한 번에 넣을 수도 있어요:

```sql
update public.games set away_starter = '곽빈', home_starter = '라일리' where id = '20270327-doosan-nc-0';
update public.games set status = 'final', away_score = 4, home_score = 6 where id = '20270327-doosan-nc-0';

-- 오늘 경기 확인
select id, start_time, away_team, home_team, away_starter, home_starter, status, away_score, home_score
  from public.games where game_date = (now() at time zone 'Asia/Seoul')::date order by start_time;  -- 서버는 UTC 라 한국 날짜로
```

## 3. 일정이 바뀌었을 때

| 상황 | 할 일 |
|---|---|
| 시작 시간 변경 | 그 경기의 `start_time` 만 수정 |
| 우천 취소 | `status` 를 `canceled` 로. 앱에 "경기 취소" 표시, 그 경기 직관 기록은 결과 없이 남음 |
| 취소 경기 재편성 | **새 줄로 추가** (새 날짜 = 새 `id`). 취소된 원래 줄은 그대로 둠 |
| 더블헤더 | 같은 날 두 줄, `game_no` 1 / 2 |
| 포스트시즌 | 대진이 정해질 때마다 줄 추가 |
| 잘못 넣은 경기 | 아무도 직관 기록을 안 했으면 줄 삭제, 했으면 `canceled` 로 |

## 비시즌

경기가 없는 날 앱은 "오늘은 경기가 없어요"와 함께 내 팀의 **다음 경기**를 보여 줍니다. 다음 시즌 일정을 올리면 자동으로 나타나요.
